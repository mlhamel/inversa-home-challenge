# packages/shared-schemas

Generated Python bindings for the `inversa.v1` protobuf contracts — **buf-owned; do not edit by hand.**

- `src/inversa/v1/` — `*_pb2.py` + `.pyi` stubs regenerated by `make proto` from [`packages/proto`](../proto/README.md)
- Merges into the `inversa` PEP 420 namespace (no `__init__.py` at `src/inversa/`)
- Typed end-to-end via `py.typed`; consumed by the Ingestion contract layer (and later the API)

Change contracts by editing the `.proto` definitions in `packages/proto` and running `make proto` — never by patching the generated files here.

Governing spec: [`specs/01-data-contracts.md`](../../specs/01-data-contracts.md)
